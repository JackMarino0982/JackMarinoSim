An evidence ID is a collection specification, not an existing artifact.
All bundles below are Not collected. Jack Marino owns collection and storage;
decision date is TBD. Actual artifact location, execution date, product and
hardware revisions, operator/reviewer identity, observed measurements, and
disposition are TBD until an executed run supplies them. These unresolved
values inherit the owner/date in each row. Do not replace them with example
Pass data or with this document's CI result.

Every collected bundle will record its evidence ID, linked check and
requirement/story, controlled baseline and parameter approvals, setup and
instrument calibration/uncertainty, raw observations, reproducible calculation,
acceptance comparison, deviations, reviewer disposition, and a usable artifact
location. Validation bundles additionally retain stakeholder feedback and
observed decisions. Revision and result are recorded only from evidence.
