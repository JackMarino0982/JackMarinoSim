This Week 2 architecture draft contains stakeholder stories, grouped candidate
requirements, separate counter and paired-FTDI bench scenarios, and linked
verification and validation plans, alongside the purpose, context, and development plan for an embedded system that converts analog input into
sampled numeric ADC readings. Hardware, electrical input limits, conversion
performance, and the output interface remain open with named decision owners
and review gates. The complete book retains later course-template chapters
as instructional scaffolding; they are not project requirements or test
evidence. Hardware implementation, verification, validation, and baseline
approval are not claimed by this draft.
